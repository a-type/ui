# ErrorBoundary

Wrap a subtree to show a fallback if a descendant throws while rendering.

```tsx
import { ErrorBoundary } from '@a-type/ui';

<ErrorBoundary
	fallback={({ error, clearError }) => (
		<div>
			<p>{error.message}</p>
			<button type="button" onClick={clearError}>
				Try again
			</button>
		</div>
	)}
>
	<App />
</ErrorBoundary>;
```

`fallback` can also be a React node. Without one, the boundary renders nothing
after an error. React error boundaries do not catch errors in event handlers.

# InfiniteLoadTrigger

Place `InfiniteLoadTrigger` after a list to request more content when the
trigger becomes visible.

```tsx
import { InfiniteLoadTrigger } from '@a-type/ui';

function LoadMoreTrigger({
	hasNextPage,
	isLoading,
	loadNextPage,
}: {
	hasNextPage: boolean;
	isLoading: boolean;
	loadNextPage: () => void;
}) {
	if (!hasNextPage || isLoading) return null;
	return <InfiniteLoadTrigger onVisible={loadNextPage} />;
}
```

It uses an `IntersectionObserver` and may call `onVisible` again when the
trigger re-enters the viewport or remounts. The caller must handle loading,
pagination, and duplicate requests.

# Provider

Import the library stylesheet and wrap your application in `Provider`.

```tsx
import '@a-type/ui/main.css';
import { Provider } from '@a-type/ui';

<Provider>
	<App />
</Provider>;
```

The provider supplies the icon spritesheet, toast and tooltip providers,
particle layer, and PWA install dialog. It also manages viewport and virtual
keyboard behavior.

- The install dialog loads `/manifest.json` by default. Pass `manifestPath` to
  change the path, or `manifestPath={false}` to disable the dialog.
- `disableParticles` omits the particle layer. Otherwise, its children render
  after the client mounts.
- `virtualKeyboardBehavior` accepts `displace` (the default) or `overlay` on
  supported browsers. `disableViewportOffset` and `disableTitleBarColor` opt
  out of those global updates.
